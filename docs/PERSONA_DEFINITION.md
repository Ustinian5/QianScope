# 黔镜 QianScope 合成人格定义与报告口径

## 1. 边界

黔镜 QianScope 的人格是用于群体模拟的稳定结构化向量，不是真实个人的复制、心理诊断或由大模型自由编写的角色提示词。内置 5,000 个原型全部标记为 `synthetic`；如果以后接入授权数据，每类字段仍必须分别标记为 `observed`、`inferred` 或 `synthetic`。

稳定人格与动态状态严格分离：事件可以改变知晓、信念、态度、情绪、风险感知、目标激活、行动、记忆和关系信任，但不能在一次推演中改写人口属性、人格特质和长期价值。

## 2. 完整人格框架

当前定义版本为 `echo-persona-definition-v3`，公开 9 组共 54 个维度：

| 框架 | 维度数 | 用途 |
| --- | ---: | --- |
| 大五人格 | 5 | 开放、尽责、外向、宜人和情绪敏感 |
| 施瓦茨价值观 | 10 | 自主、探索、成就、影响力、安全、规则、传统、善意、普遍关怀和生活体验 |
| 道德基础 | 6 | 关怀、公平、忠诚、权威、纯洁和自由线索敏感度 |
| 风险偏好 | 5 | 总体、财务、社交、技术和健康风险容忍度 |
| 认知风格 | 4 | 分析—直觉、社会参照—独立、短期—长期、经验—证据 |
| 目标系统 | 7 | 稳定、成就、位置、归属、成长、意义和基本保障 |
| 稳定信念 | 6 | 技术、经济、品牌、机构、社会合作和判断置信 |
| 信息与行动 | 6 | 社会/机构信任、怀疑、表达、行动和网络影响 |
| 信息渠道 | 5 | 社交媒体、新闻、熟人、社区和主动搜索 |

每个维度同时返回内部字段、中文名称、定义、分数、量尺端点、两端含义和当前解释。双极认知轴使用 `[-1, 1]`；其余维度使用 `[0, 1]`。信息渠道五项的相对权重合计约为 1。高分只表示该倾向在模型中更强，不表示能力或道德水平更高。

## 3. 人格档案契约

`GET /v1/personas/{persona_id}` 返回：

- 本地化人口属性、社会角色和单位类型；
- 9 组完整人格框架，以及兼容界面使用的排序特质和价值列表；
- 主目标、兴趣、信息渠道、当前状态、记忆、日程、地点和关系；
- `model_version`、`data_version`、`definition_version`、`source_id`；
- 分节字段来源、`profile_hash` 和 `profile_completeness`。

同一人口版本、人口 ID、种子和行号会产生同一 `persona_id`。`profile_hash` 绑定人口属性、单位类型、人格、价值、目标和认知风格；版本升级造成定义变化时必须同时升级模型或数据版本。

## 4. 问卷结果中的人格使用

每道问卷先为每个 Agent 计算逐选项概率，再使用同一调查权重汇总。默认报告按年龄、性别、社会角色、单位类型、教育背景和主要信息渠道输出交叉表。每个单元格同时包含：

- 原型数量；
- 加权代表规模和权重占比；
- 全部回答分布或数值题均值；
- 该组主要回答。

每道题最多输出 3 条“合成代表性回答”。回答只能引用该原型的社会角色、单位类型、目标、价值、渠道、状态和用户输入的问题；界面必须持续标明它不是现实受访者原话。

## 5. 报告质量门

每次正式预测随结果写入运行元数据和自动检查：模型/数据版本、种子、路径数、时长、情景数、请求/成功/失败 Agent 数、代表规模、有效样本量、人口来源、加权方法、区间定义、校准状态和人口签名。

当前质量门检查区间顺序、互斥选项概率守恒、行动分布守恒、Agent 完成率、区间是否过度重合、交叉表覆盖、代表性回答覆盖、历史校准、人口口径、未来信息隔离和题目语义覆盖。任何硬失败都会在报告中显示为失败；未校准或未接入现实人口边际属于明确提醒，不能被隐藏成“已验证”。

## 6. 仍需现实数据才能提升的部分

完整结构不等于现实有效性。要把合成人格结果用于现实预测，还必须补充：

1. 有授权且去标识化的人口边际及来源年份；
2. 在预测锁定时点前可用的历史问卷与事件结果；
3. 时间留出回测、分布漂移监测和真实结果持续回填；
4. 经授权的真实关系、地点、交通和行为聚合数据。

在这些数据完成前，系统只能确定地称为“结构完整、可复现、未充分现实校准的合成人格社会模拟”。
