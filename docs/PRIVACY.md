# Privacy

The bundled data is synthetic. External data must be licensed/authorized, consented where necessary, de-identified, purpose-limited, and time-bounded. APIs should be deployed behind authentication before real data is accepted. Reports must suppress cells smaller than `ECHO_MIN_SEGMENT_SIZE` and avoid person-level claims.

Deletion and retention policies belong to the storage adapter and deployment jurisdiction; local v0.1 does not present itself as a compliant repository for personal data.
