# ADR 0001: System boundary

- Status: Accepted
- Date: 2026-08-24

## Decision

Build a constrained, probabilistic social-world-model substrate rather than a conversational multi-agent clone. The first delivery targets E0-E2 and the executable parts of E3, with interfaces for LLM teachers and later latent models.

## Consequences

The system remains useful without an API key, while an OpenAI-compatible provider can improve semantic normalization and selected high-uncertainty actions. Claims are limited to measured synthetic/offline performance and explicit applicability boundaries.
