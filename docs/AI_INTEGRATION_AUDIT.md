# DeepSeek V4 Flash 集成审计

状态：2026-08-30 已完成代码接入与真实供应商调用验证。

## 审计结论

改造前，仓库虽然已有 OpenAI-compatible 适配器，但主要只在自然语言事件/城市编译和无显式价值信号时的研究语义解释中使用。默认事件模板、默认城市情景、社会世界多轮问题、九类洞察和人物访谈均由固定规则生成；适配器默认温度为 0，并会复用内容缓存。因此“已经配置模型”不等于“所有用户生成操作真的调用模型”，重复输入也通常不会变化。

改造后，公开站的服务端配置为：

```dotenv
QIANSCOPE_LLM_BASE_URL=https://api.deepseek.com
QIANSCOPE_LLM_MODEL=deepseek-v4-flash
QIANSCOPE_LLM_REQUIRED=true
```

API Key 只进入 API 服务环境变量。浏览器和 Next.js Web 服务均不持有 Key。

## 业务覆盖

| 用户操作 | DeepSeek 的实际职责 | 数值内核的职责 | 变化来源 |
| --- | --- | --- | --- |
| 事件预演（自然语言） | 生成候选事件、机制、先验与干预结构 | 联合路径、概率曲线、反事实 | 非零温度 + 变化 ID |
| 事件预演（内置/结构化） | 刷新非历史候选的危险率与严重度假设 | 同上 | 每次非缓存调用 |
| 城市模拟（自然语言） | 编译事件、分支和干预 | 微观状态、区县与城市指标 | 非零温度 + 变化 ID |
| 城市模拟（默认/结构化） | 刷新事件强度、信息效价、可信度和干预效力 | 同上 | 每次非缓存调用 |
| 社会世界 / 事件剧本 | 生成事件语义信号和完整多轮独立决策脚本 | 5,000 人格的逐轮分类决策、传播和状态路径 | 每次专属剧本 |
| 严肃问卷预测 | 解释事件语义；按已算分布生成结论、分群解释与合成人格回答 | 问卷概率、反事实、区间、校准 | 两次非缓存调用 |
| 人物访谈 | 严格基于当前合成人格档案生成第一人称回答 | 人格档案、关系和状态约束 | 每问一次实时调用 |
| 九类洞察工具 | 生成解释、限制与代表性叙述 | 分群评分与条形数值 | 每次实时生成 |

数据录入、Schema 校验、人口生成、概率校准和回放校验仍是确定性基础设施，不把大模型调用当作装饰性依赖。

## 可核验回执

AI 支持的结果包含 `ai_execution`：

- `provider` 与 `model`
- DeepSeek `provider_call_id`
- `cache_hit`
- 输入、输出与总 token 数
- 本次 `variation_id`

回执不含 API Key、Authorization Header、完整提示词或隐藏推理。

## 失败与安全边界

- 开启 `QIANSCOPE_LLM_REQUIRED=true` 但缺少 Key/模型时，API 服务拒绝启动。
- 已配置模型但调用失败、超时或 JSON Schema 校验失败时，对应操作明确失败，不会伪装为本地生成成功。
- LLM 不直接输出最终概率。所有概率、P10/P50/P90、传播路径、反事实差值和校准仍由可审计数值内核计算。
- 合成人格回答不是现实受访者原话；页面和结果继续保留该限制说明。
- 公网免登录使用会消耗项目方额度，部署侧仍应监控调用量、并发、余额与异常流量。
