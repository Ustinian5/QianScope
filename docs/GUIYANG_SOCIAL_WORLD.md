# 贵阳 Social World 统一配置

## 城市口径

- 默认世界：`guiyang_social_world`
- 稳定合成人格原型：5,000
- 加权代表人口：6,668,900
- 人口统计口径：贵阳市统计局、国家统计局贵阳调查队《2025 年贵阳市国民经济和社会发展统计公报》
- 赛事核心地点：贵阳国际会议展览中心

“代表人口”是 5,000 个合成原型的权重之和，不表示系统保存了 6,668,900 个真实个人，也不表示同时运行同量独立大模型进程。人格、关系、日程和当前位置均为合成数据；预测结果是给定事件、参数和种子的条件推演，不是对现实个体的识别或无条件预言。

## 前后端约束

- 后端人格接口返回的 `scene_location_id` 必须属于上表 7 个 ID；每个场景至少有一个可检索人格。
- 后端世界运行时可使用更细的语义地点，但必须显式映射到一个地图场景，不能静默回退到默认地点。
- 从地图或引导故事发起事件时，所选地点必须写入事件的 `source_location_id` 和 `target_location_ids`，保证地点不是纯展示字段。
- 人口热区、人格位置、场景卡片和 2.5D 交互画页统一使用相同地点 ID。

## 贵客松第一阶段场景

本阶段用“贵阳国际会议展览中心活动高峰客流”为内置事件：模拟集中入场、公共交通接驳、现场信息触达和服务分流在不同策略下的条件变化。后续可沿赛事的真实业务方向扩展到贵州文旅、酒业、能源和公共服务，但必须先补充有权使用的数据、历史事件回测与效果校准。
