# 苏州城市社会世界模型

> 归档说明：这是迁移前的苏州研究适配器，不参与贵州默认产品路径或新项目部署。

## 1. 实现边界

该模块是基于公开产品描述与公开统计资料进行的 clean-room 功能实现。它模拟“城市主体—关系—行动—环境—信息—协调—涌现—反事实”联合演化，但不声称获得、复现或推断任何第三方的私有代码、参数、训练数据或真实居民微观数据。

模型回答的是：在明确的初始条件、事件假设和干预机制下，不同政策分支的城市指标分布如何演化。它不是现实结果保证，也不是已完成因果识别的政策评估工具。

## 3. 八层城市表示

1. **主体层**：5,000–250,000 个加权合成人口原型，每个原型带区县、家庭、年龄、教育、就业、行业、收入、通勤、信任、风险与公共服务需求状态。
2. **关系层**：家庭、工作地、区县邻近和线上关系四层 multiplex graph；边分别带强度与信任。
3. **行动层**：就业保持、消费、出行、信息接受、医疗需求与政策响应均为概率状态转移。
4. **环境层**：10 个区县、近似质心、行业结构、GDP、人口、交通和医疗容量。
5. **信息层**：事件信息价态、可信度、数字亲和、机构信任、邻居传播放在同一个更新方程中。
6. **协调层**：交通补贴、消费券、中小企业支持、医疗扩容、权威信息发布和预算可以按区县/人群组合。
7. **涌现层**：由微观状态加权聚合出就业、消费、信任、满意度、拥堵、医疗负载、传言与压力轨迹。
8. **反事实层**：同一初态、同一事件与同一随机流下比较控制组和多个干预分支。

所有个人、家庭、关系、企业原型与行为状态都是合成数据。原型权重在每个区县内精确闭合至缩放后的代表人口；全市加权收入均值精确校准至公开锚点；城镇人口使用受约束分配而不是独立随机抽样。

## 4. 联合演化内核

每日更新按如下依赖顺序执行：

```text
外生事件 + 分支干预
  -> 就业概率与经济信心
  -> 出行需求、拥堵和通勤时间
  -> 健康需求、区县容量与医疗负载
  -> 多层关系传播、认知与传言相信度
  -> 压力、消费、政府信任和生活满意度
  -> 全市 / Scope / 区县聚合
```

核心形式是带边界的状态转移：

```text
x(t+1) = clip(A*x(t) + B*neighbor(x,t) + C*event(t)
              + D*intervention(t) + epsilon(path,t), 0, 1)
```

其中 `neighbor` 由多层关系的边强度、信任和层权重聚合；拥堵和医疗负载由区县加权需求除以校准容量得到。就业率只在适龄非在校劳动力范围内计算。机制系数目前是显式、可检查的场景参数，还没有被描述为真实世界因果系数。

## 5. ScopeQuery 与 K 路径

`CityScopeQuery` 可以限定区县、人群、时间范围、指标、事件和政策分支。支持的人群包括青年、老年、流动人口、制造业职工、服务业职工、学生和低收入人群。

每个分支运行 K 条蒙特卡洛路径，输出每一天的 P10/P50/P90、均值和标准差。所有反事实分支对同一个 K 使用 common random numbers，因此分支差值主要反映干预，而不是不同随机抽样造成的差异。区间表示模型内的场景不确定性，不等于具有经验覆盖保证的统计置信区间。

## 6. 大模型接入

设置以下环境变量后无需改代码：

```dotenv
ECHO_LLM_API_KEY=your-key
ECHO_LLM_BASE_URL=https://your-provider.example/v1
ECHO_LLM_MODEL=your-model-id
```

大模型只承担“自然语言 → 严格 JSON ScopeQuery”的编译工作。输出必须通过 Pydantic schema、城市 ID、区县 ID、人群、指标、天数和样本数约束；随后由数值内核计算。API 密钥不会写入结果、缓存元数据、报告或回放日志。

```bash
curl -X POST http://127.0.0.1:8000/v1/cities/suzhou/simulate \
  -H "Content-Type: application/json" \
  -d '{
    "prototype_count": 15000,
    "samples": 8,
    "seed": 2026,
    "natural_language_prompt": "模拟昆山和园区外贸走弱，比较交通补贴与综合纾困"
  }'
```

没有大模型 API 时，可以直接提交 `CityScopeQuery`，或运行仓库内的 `scenarios/suzhou_city_resilience.json`。

## 7. 结果、血缘与回放

每次运行生成：

- `forecast.json`：完整查询、数据/模型版本、轨迹分布、区县结果与反事实差值；
- `trajectory.csv`：适合分析和绘图的长表；
- `district_final.parquet`：区县末期分布；
- `run_manifest.json`：查询、世界、输出、随机种子和版本哈希；
- `replay.jsonl`：每分支、路径、日期的宏观哈希和全状态哈希；
- `snapshots/*.npz`：关键日完整微观状态，用 SHA-256 与回放记录双向校验；
- `city_report.html`：可离线打开的中文报告。

`echo-swm city replay RUN_ID` 同时检查记录数量、唯一性、完整状态 checkpoint 内容和记录哈希。

## 8. 当前能力边界与下一步校准

当前版本完成的是“可运行、可约束、可分支、可回放”的苏州数字社会底座。若要把它升级为可用于实际政策研究的模型，仍需引入有授权的数据做外部校准和回测，例如区县年龄结构、真实 OD、行业就业、服务利用、历史事件面板、问卷/舆情抽样和政策实施记录，并执行留出时间窗与最差区县误差验证。

禁止将合成微观原型误认为真实居民，禁止据此对具体个人作高风险决定、重新识别、隐性操纵或绕过合规审查。
