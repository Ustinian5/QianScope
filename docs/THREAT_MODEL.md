# Threat model

Primary threats are future-information leakage, prompt injection in event text, API key disclosure, re-identification, small-cell inference, biased targeting, replay tampering, unbounded provider cost, and false certainty. Controls include typed schemas, availability-time checks, secret-only environment configuration, aggregate-language warnings, minimum cells, hash-verified snapshots, LLM budgets/timeouts/cache, and explicit use restrictions.
