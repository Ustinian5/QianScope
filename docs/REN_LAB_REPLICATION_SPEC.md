# 境瞳 Social Simulator clean-room 复刻规格

> 归档说明：本文是苏州版 L1/L2/L3 产品规格，仅保留作回归参考；当前贵州默认世界以 [`GUIYANG_SOCIAL_WORLD.md`](GUIYANG_SOCIAL_WORLD.md) 为准。

状态：发布候选验证中  
基准：`https://social.renlab.ai/` 登录后产品（2026-08-25 实机审计）  
原则：复刻可观察到的功能、交互和信息架构；不复制对方源码、私有素材或品牌标识。

最新逐项对照、三维升级结果和未复现边界见 [`TARGET_PARITY_AUDIT.md`](TARGET_PARITY_AUDIT.md)。

## 1. 产品骨架

目标产品不是单一问卷页，而是一个可下钻的社会世界：

1. L1 苏州宏观层：真实城市底图、人群活动、地标入口、天气时间、搜索和社会推演工具。
2. L2 场所层：校园、商场、公园、住宅等局部三维场景，人物按日程移动并可被选择。
3. L3 建筑层：楼宇与楼层入口、房间/场景热点、返回上一级。
4. 人物层：档案、生活线索、状态、关系图、人物访谈和当事人交叉校验。
5. 推演层：问卷、事件及多类研究工具，采用后台任务、进度、取消、结果和分群解释的统一模式。

## 2. L1 苏州宏观层

必须具备：

- 全视口地图，不使用传统网站页头。
- 左上品牌卡：产品名、中国标准时间、苏州实时天气、产品说明。
- 人物搜索：支持姓名、角色、标签和地点，展示“代表人口”口径。
- 地图引擎：正式环境使用高德 Maps JavaScript API 2.0；Key 与安全密钥必须来自 Web 端应用，禁止盗用、转存或伪装第三方凭证。
- 地图控制：底图名称、活动层切换、加载/运行状态、缩放、俯仰和视角复位。
- 地图交互：鼠标/单指拖动、滚轮/双指缩放、双击缩放、键盘平移、Ctrl + 拖动旋转与三维俯仰。
- 城市入口：南京大学苏州校区为核心高亮节点，并包含太湖科学城、狮山、平江路、金鸡湖、独墅湖和太湖新城。
- 点击节点进入 L2；返回时恢复原地图视角和工具状态。
- 人群层：通勤/步行/线上活动信号，事件运行时用颜色表示触达和情绪。
- 社会推演工具启动器和永久可信度说明。
- “带我看戏”导览入口，能选择预置事件剧本并播放时间线。

## 3. L2/L3 场景

L2 必须具备：

- 可旋转、缩放、平移和复位的场景。
- 场所标题、说明和“返回苏州全景”。
- 建筑、道路、绿地、水体、天气、昼夜和活动人物。
- 可访谈人物有明确视觉标识；背景人物不可伪装成可访谈人物。
- 点击人物聚焦镜头并打开人物面板。
- 建筑热点进入 L3；进入/退出过程有加载和空间连续性反馈。

L3 必须具备：

- 当前建筑与楼层标题。
- 楼层导航、室内热点、返回楼外/上一层。
- 同一人物在 L2/L3 之间保持身份与状态一致。

## 4. 人物体验

人物面板字段：

- 姓名、身份、角色、院系/组织、简历摘要。
- AI 模拟声明；真实公众人物与合成人物采用不同说明。
- 性格、价值观、目标、当前情绪、压力、信念、意图和当前行动。
- 生活线索、近期记忆、计划与日程。
- 一度人脉关系图，节点可继续打开另一个人物。
- 访谈输入、推荐问题、思考态、回答、引用状态卡。
- 认知边界拒答提示。
- 涉及第三人的回答可请求“问问当事人”，并展示两方叙述差异。

## 5. 社会推演工具

### 5.1 问卷调查

输入：问题、可选的逗号分隔选项。留空选项时允许自由回答。  
运行：显示作答进度、代表性思考流和终止按钮。  
结果：总作答数、立场分布、分群拆解、代表性回答、细分人群卡片。

### 5.2 事件推演

输入：事件文本、1 天/3 天/1 周/1 月/1 学期。  
运行：事件按渠道和关系扩散，未触达人群不产生事件反应。  
结果：触达人数和逐轮曲线、K 因子、渠道种子、口碑触达、行为影响率、情绪、强度、分群、行为变化、涌现风险和代表性轨迹。

### 5.3 洞察工具

| 工具 | 输入 | 结果 |
| --- | --- | --- |
| 营销活动模拟 | 活动事件、窗口 | 复用事件推演结果 |
| 趋势探测 | 趋势词、窗口 | 关注度、触达人数、判定 |
| 品牌洞察 | 品牌 | NPS、正中负面分布、印象词 |
| 产品洞察 | 至少两个候选功能 | 功能得票率、排序、代表原因 |
| 模拟需求信号 | 需求问题、选项 | 复用问卷结果，明确“模拟需求”口径 |
| 定价测试 | 产品、价格点、目标人群 | 最优价、需求曲线、营收指数 |
| 竞品反应 | 双方品牌、竞品动作、可选历史摘要 | 对手画像、威胁/优势/弱点、三项应对动作 |
| 转化漏斗 | 产品方案、渠道 | 各层留存、掉落、主要障碍 |
| 流失预测 | 变化事件、窗口 | 流失率、原因、分群、预计留存 |
| 达人智配 | 品牌投放需求 | 匹配列表、理由、达人详情 |

## 6. 统一任务交互

- 创建任务后立即返回任务 ID。
- 运行态包含进度、阶段文案、已处理人数和最新代表性思考。
- 支持主动终止；当前在安全计算边界生效，不发布不完整结果。
- 同一时间资源忙时提供排队/重试反馈。
- 结果面板可以停靠，不阻挡地图继续探索。
- 不允许以硬编码数字冒充真实推演结果；缺失字段明确显示未产出。

| 任务运行 | `jobs.manager` 与 `/v1/jobs*` | 已实现排队、真实阶段、终止、持久化和按 ID 恢复 |

## 8. 验收标准

完成不能只以“页面长得像”为准，必须逐项证明：

- 12 个工具均可从创建运行到结果，且结果来自真实运行或明确标注的演示数据。
- 城市、场所、建筑、人物四层导航可以往返且状态不丢失。
- 人物搜索、档案、关系和访谈全部可用。
- 问卷和事件结果与后端产物一致，刷新后可按运行 ID 恢复。
- 5,000 原型运行、1,304.77 万代表人口的口径在所有页面一致。
- 电脑端主展示布局与键盘操作、焦点状态完整；手机适配不属于当前产品验收范围。
- 前端 lint、严格 TypeScript、生产构建通过；后端 Ruff、mypy 和测试通过。
- 使用两边实机截图和交互清单逐项对照，不以单个首页截图代替完成证明。

## 9. 明确差异与发布边界

- 这是 clean-room 功能复刻，不使用境瞳品牌、私有代码、私有数据、模型权重或受限素材；视觉系统为黔镜 QianScope 自有实现。
- 当前内置 5,000 个是稳定、可检索、实际参与计算的合成人格原型；1,304.77 万是加权代表人口，不宣称存在同量独立 LLM 进程。
- 任务终止采用安全边界，当前不会把不完整样本包装成正式“部分结果”。若后续必须逐批输出部分报告，需要各数值运行时增加可中断聚合契约。
- 当前贵阳版采用 OpenFlipbook 风格的 2.5D 画页，具备平移、缩放、人物选择、地点进入、楼层路径和多类室内；该选择不再追求目标站的实时 Three.js 复刻。
- 预置导览不会展示硬编码预测数字；它只负责预填可复现事件，并进入同一真实后台任务。
- 高德 Web JS API Key 与安全密钥未配置或失效时，OpenStreetMap/MapLibre 只作为明确标注的开发降级；生产发布必须配置有权使用的高德 Web 端应用凭证并保留法定审图号与署名。
