# 境瞳目标站对照审计与发布边界

> 归档说明：本文记录 2026-08-26 的苏州版 clean-room 验收基线，不代表当前贵州默认世界；贵州实现以 [`GUIYANG_SOCIAL_WORLD.md`](GUIYANG_SOCIAL_WORLD.md) 为准。

审计日期：2026-08-26
对照对象：`https://social.renlab.ai/` 登录后产品
当前结论：**可公开观察的核心产品旅程已完成 clean-room 对齐；私有数据、私有模型、真实达人库和原始三维资产仍不能声称复刻完成。**

> 本轮重新访问目标站时页面未能稳定加载，因此目标站一侧以此前实际走查记录、`website-gap-audit.md` 和公开可观察行为为基线；没有重新验证到的内容不作新增推断。

## 1. 已经闭环的主产品旅程

```text
苏州城市地图
  → 选择地点 / 动态人格
  → 独立三维场景
  → 建筑与真实差异楼层
  → 人格档案 / 关系 / 访谈
  → 问卷或通用事件任务
  → 任务中心
  → 可交互、可导出、可分享的报告
```

当前实现不是静态演示：高德地图、5,000 人格活动层、人物接口、任务状态、问卷与事件运行、结果恢复和报告读取均已连接真实后端。后端不可用或任务失败时不生成报告，也不会切换到固定的合成演示结果。

## 4. 不能标记为“完全复刻”的剩余项

### A. 必须由外部数据或服务补全

1. **邮箱 Magic Link、账号和团队权限**
   当前是公开单用户研究原型，没有账号、组织、任务 owner 和额度隔离。要生产化需确定认证服务和邮件发送服务，并提供回调域名与密钥。

2. **真实达人/KOL 数据库**
   当前“达人智配”是合成人格关系网络中的传播节点，不是真实平台账号。目标站的账号、粉丝、报价、互动率、作品与验证链接需要合法数据源和持续更新协议。

3. **有授权的真实人口边际与历史结果**
   当前 5,000 个稳定人格原型加权代表 1,304.77 万人口，但不是 1,304.77 万个独立 Agent。没有授权人口分布和历史揭晓结果时，只能表达为未校准条件预测。

4. **真实校园/城市三维资产**
   当前为自研程序化模型。要达到网格、立面、地形和室内陈设的测绘级一致，需要团队自建或获授权的 GLB/GLTF、建筑足迹、高程和纹理。

5. **生产数据层**
   多用户发布需 PostgreSQL、Redis/任务队列、对象存储/CDN、备份与审计日志；当前文件产物和进程内任务管理只适合单实例原型。

6. **线上可观测性**
   仍需真实的错误监控/RUM 项目与告警接收端。没有 DSN 或账号时不能完成生产监测闭环。

### B. 仍需继续开发

1. 人物按道路图寻路、室内外连续行程、局部避障和交通工具层；当前是稳定合成行程动画。
2. 剧本自动摄影机：按时间轴切换地点、人物、关系传播节点和结果镜头。
3. 真实太阳高度、阴影、降雨和室内灯光与天气连续耦合。
4. 高德/兜底底图的用户手动切换；当前只有自动降级。
5. PWA Service Worker、离线壳和更新提示；当前已有 Manifest，但不是完整离线应用。
6. 服务器生成的不可变 PDF/PNG 报告；当前 PDF 使用浏览器打印，CSV/JSON 使用后端导出。
7. 任务中心的团队共享、归档、重跑、批量对比和跨设备历史；当前历史保存在本机浏览器。
8. 地图与三维依赖已独立懒加载，但生产包中的 MapLibre 和三维分块仍偏大，需继续做按能力加载与模型压缩。

## 5. “千万 Agent”口径

- 当前实际参与正式运行的是至少 **5,000 个稳定人格原型**，可扩展到 20,000。
- 每个原型均有稳定身份、人格、状态、记忆和关系，并进入 `observe → decide → act → remember` 循环。
- `1,304.77 万` 是加权代表人口，不是后台常驻 1,304.77 万个 LLM 进程。
- 在没有对方私有人格数据、训练数据和权重时，不能科学地宣称与境瞳“人格资产完全相同”。

## 7. 发布判定

当前版本可以发布为：

> **开源、可运行、可复现的 5,000+ 稳定合成人格社会世界与通用事件预测系统。**

当前版本不能发布为：

> 与境瞳私有模型、私有数据、真实达人库或原始三维资产完全相同的复制品。

该边界不是措辞保守，而是目前代码和证据能够支持的确定结论。
