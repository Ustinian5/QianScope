# Data card: synthetic-demo-v1

The dataset contains 5,000–20,000 generated participants with age, education, income, occupation proxy, risk preference, price sensitivity, technology acceptance, brand trust, peer sensitivity, prior purchase, survey weight, randomized treatment, and pre/post outcomes.

It contains no real human data. Ground-truth probability columns are generated for evaluation and excluded from all inference features. The generator and seed are recorded in Parquet metadata and the data manifest.
